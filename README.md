# Auto Ticket Classification Using Flow Designer

## Project Description

This project demonstrates an automated ticket classification system using **ServiceNow Flow Designer**. The workflow is designed to evaluate incoming support tickets, classify them based on predefined conditions, and route them to the appropriate assignment group.

The automation helps reduce manual ticket classification, improve ticket routing, and ensure that support requests are directed to the appropriate team.

## Project Objectives

- Automate the classification of support tickets.
- Reduce manual ticket assignment.
- Route tickets to the appropriate assignment group.
- Improve the efficiency of IT service management.
- Demonstrate workflow automation using ServiceNow Flow Designer.

## Technologies Used

- ServiceNow
- Flow Designer
- Incident/Ticket Management
- Workflow Automation
- Data Pills
- Conditional Logic

## Project Workflow

1. A support ticket is created or updated.
2. The Flow Designer workflow is triggered.
3. Ticket information is evaluated using configured conditions.
4. The appropriate ticket classification is determined.
5. The ticket is assigned to the relevant assignment group.
6. The ticket record is updated with the required information.

## Example Classification

| Ticket Type | Classification | Assignment Group |
|---|---|---|
| Laptop, keyboard, mouse | Hardware | Hardware |
